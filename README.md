# ccna-networking-labs
🚀 Laboratorios prácticos para la certificación Cisco CCNA 200-301 en Packet Tracer. Incluye topologías (.pkt), configuraciones (.cfg) y guías paso a paso de Fundamentos de Red, Switching, Routing, Servicios IP, Seguridad (ACLs) y Automatización.

Bienvenido a mi repositorio personal de preparación para la certificación **Cisco Certified Network Associate (CCNA 200-301)**. 

Este repositorio reúne laboratorios prácticos desarrollados en **Cisco Packet Tracer**, enfocados en la configuración, verificación y *troubleshooting* de infraestructura de red bajo los estándares y mejores prácticas de Cisco.
